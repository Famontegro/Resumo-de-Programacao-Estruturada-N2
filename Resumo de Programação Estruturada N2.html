Alocação dinâmica de memória

Cai na prova: Revisão P2 questões 1 e 2 (vetor de structs e matriz de temperaturas alocados com malloc) e a Lista A inteira.

8.1O que é e por que usar

Uma variável comum, como int v[100], tem o tamanho fixado na hora de escrever o programa. Se o usuário precisar de 3 posições você desperdiça 97; se precisar de 101, o programa quebra. Na alocação dinâmica o programa pede a memória durante a execução, no tamanho que for preciso, e o programador decide quando criá-la e quando destruí-la (PEREIRA, 2016, citado no slide).

Variável comumVariável dinâmica
Tamanhofixo, definido ao compilardefinido durante a execução
Quem cria e destróio compilador (ao entrar e sair do bloco)você, com malloc e free
Onde morapilha (stack)heap
Acessopelo nome da variávelpor um ponteiro que guarda o endereço

8.2As três ferramentas: sizeof, malloc, free

FunçãoO que fazDetalhe que cai em prova
sizeof(x)quantidade de bytes para guardar x (tipo ou variável)o tamanho muda de máquina para máquina, então nunca escreva "4" na mão
malloc(n)reserva n bytes e devolve o endereço do blocorecebe bytes, não quantidade de elementos. Devolve NULL se falhar
free(p)devolve o bloco ao sistemasó funciona em endereço que veio de malloc/calloc/realloc, e uma única vez

Todas ficam em <stdlib.h> (sizeof é operador da linguagem, não precisa de biblioteca). O ciclo de vida é sempre o mesmo, igual ao desenho do slide: (a) alocar, (b) usar, (c) liberar.

a8_ciclo.c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *p = malloc(sizeof(int));   // (a) reserva 4 bytes no heap
    if (p == NULL) {                // sempre teste o retorno
        printf("Erro na alocacao\n");
        return 1;
    }
    *p = 5;                         // (b) usa a memoria
    printf("Valor: %d\n", *p);
    free(p);                        // (c) devolve a memoria
    p = NULL;                       // boa pratica: evita ponteiro "pendurado"
    return 0;
}
Valor: 5

8.3Segurança e casting

Se não houver memória disponível, malloc devolve NULL. Usar esse ponteiro derruba o programa, então o slide mostra o teste logo depois de alocar:

padrão do slide
void *ptr;
ptr = malloc(size);          // aloca uma área
if (!ptr) {                  // testa a alocação
    printf("Erro na alocacao\n");
    exit(1);                 // encerra o programa (stdlib.h)
}

O malloc devolve void* (ponteiro genérico). O slide mostra o casting ptr = (tipo*) malloc(size);. Em C ele é opcional, porque void* converte sozinho para qualquer ponteiro; em C++ ele é obrigatório. Se a prova usar o casting, é só escrever (int*) malloc(...).

Dica

if (!ptr) e if (ptr == NULL) são a mesma coisa. Use a que você ler com mais facilidade.

8.4Vetor dinâmico

Para um vetor de tam inteiros, peça tam * sizeof(int) bytes. O ponteiro devolvido já funciona como vetor: vet[i] e *(vet + i) são exatamente o mesmo acesso. Somar i a um ponteiro avança i elementos (i * sizeof(int) bytes), não i bytes.

a8_vetor.c (exemplo do slide, com free)
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    int i, tam, *vet;
    printf("Digite o tamanho do vetor: ");
    scanf("%d", &tam);
    srand(time(NULL));

    vet = malloc(tam * sizeof(int));
    if (vet) {
        printf("Memoria alocada com sucesso!\n");
        for (i = 0; i < tam; i++)
            *(vet + i) = rand() % 100;      // o mesmo que vet[i]
        for (i = 0; i < tam; i++)
            printf("%d ", *(vet + i));
        printf("\n");
        free(vet);                           // nao esquecer!
    } else {
        printf("Erro ao alocar memoria!\n");
    }
    return 0;
}

Atenção

O código do slide não chama free(vet). Em um programa curto o sistema recolhe a memória ao terminar, mas em prova e em trabalho escreva sempre o free.

8.5Matriz dinâmica com ponteiro de ponteiro

Uma matriz dinâmica são duas camadas: um vetor de ponteiros (um por linha) e, para cada linha, um vetor com as colunas. O tipo é int **mat. Depois de alocada, mat[i][j] funciona como em uma matriz comum.

a8_matriz.c (exemplo do slide)
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define LIN 4
#define COL 6

int main(void) {
    int **mat;
    int i, j;
    srand(time(NULL));

    // 1) vetor de LIN ponteiros (um por linha)
    mat = malloc(LIN * sizeof(int *));
    // 2) cada linha e um vetor de COL inteiros
    for (i = 0; i < LIN; i++)
        mat[i] = malloc(COL * sizeof(int));

    for (i = 0; i < LIN; i++)
        for (j = 0; j < COL; j++)
            mat[i][j] = rand() % 100;

    printf("Matriz gerada com numeros aleatorios:\n");
    for (i = 0; i < LIN; i++) {
        for (j = 0; j < COL; j++)
            printf("%2d ", mat[i][j]);
        printf("\n");
    }

    // liberar na ordem inversa: primeiro as linhas, depois o vetor de ponteiros
    for (i = 0; i < LIN; i++)
        free(mat[i]);
    free(mat);
    return 0;
}
Erro clássico

Liberar só mat. As linhas ficam perdidas no heap (vazamento) e você ainda perde o único jeito de chegar até elas. A ordem certa é linhas primeiro (free(mat[i]) em um laço) e depois free(mat).

8.6calloc e realloc (extra, aparece na Lista C20)

  • calloc(qtd, tamanho) aloca qtd * tamanho bytes e zera tudo. O malloc deixa lixo.
  • realloc(p, novoTamanho) muda o tamanho de um bloco já alocado, preservando o conteúdo. Pode devolver outro endereço, então use o valor de retorno.
a8_realloc.c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *v = NULL, n = 0, cap = 0, x, i;

    printf("Digite inteiros (0 para parar): ");
    while (scanf("%d", &x) == 1 && x != 0) {
        if (n == cap) {                          // acabou o espaco: dobra a capacidade
            cap = (cap == 0) ? 2 : cap * 2;
            int *tmp = realloc(v, cap * sizeof(int));
            if (tmp == NULL) {                   // falhou: v continua valido
                free(v);
                return 1;
            }
            v = tmp;
        }
        v[n++] = x;
    }

    for (i = 0; i < n; i++)
        printf("%d ", v[i]);
    printf("\n(%d valores, capacidade %d)\n", n, cap);
    free(v);

    int *zeros = calloc(5, sizeof(int));         // calloc: aloca E zera
    if (zeros) {
        for (i = 0; i < 5; i++) printf("%d ", zeros[i]);
        printf("\n");
        free(zeros);
    }
    return 0;
}

Padrão seguro do realloc

Nunca escreva v = realloc(v, ...). Se falhar, ele devolve NULL e você perde o endereço do bloco antigo. Guarde em uma variável temporária (tmp), teste, e só então copie para v.

8.7Revisão relâmpago de ponteiros (Lista A)

  • int *p; declara um ponteiro para int. p = &x; guarda o endereço de x.
  • *p é a indireção: acessa o valor que está no endereço. *p = 0; altera x.
  • O nome de um vetor é o endereço do primeiro elemento: int *p = v; funciona sem o &.
  • Para uma função alterar a variável de quem chamou, passe o endereço (&x) e receba um ponteiro.
  • Para imprimir endereço use %p (com cast para (void *)).
a8_ponteiros.c (Lista A1 e A3)
#include <stdio.h>

int main(void) {
    char c;   int i;   long l;   float f;   double d;
    char *pc = &c;  int *pi = &i;  long *pl = &l;  float *pf = &f;  double *pd = &d;

    printf("char, int, long, float, double: ");
    scanf(" %c %d %ld %f %lf", &c, &i, &l, &f, &d);

    printf("char   em %p = %c\n",  (void *)pc, *pc);
    printf("int    em %p = %d\n",  (void *)pi, *pi);
    printf("long   em %p = %ld\n", (void *)pl, *pl);
    printf("float  em %p = %.2f\n",(void *)pf, *pf);
    printf("double em %p = %.2f\n",(void *)pd, *pd);

    printf("\nsizeof: char=%zu int=%zu long=%zu float=%zu double=%zu\n",
           sizeof(char), sizeof(int), sizeof(long), sizeof(float), sizeof(double));
    return 0;
}

0 / 3

Qual linha aloca corretamente um vetor de 10 números double?

malloc trabalha em bytes: 10 elementos de sizeof(double) bytes cada. A primeira reserva só 10 bytes e a última guarda um ponteiro em uma variável que não é ponteiro.

Uma matriz int **m foi criada com 1 malloc para o vetor de ponteiros e 5 mallocs para as linhas. Quantos free são necessários?

Um free por malloc: 5 linhas mais o vetor de ponteiros. As linhas são liberadas antes do vetor.

O que o programa abaixo tem de errado?

trecho
int *p = malloc(sizeof(int));
*p = 7;
free(p);
printf("%d", *p);

Depois do free(p) o endereço não pertence mais ao programa. Pode imprimir 7, lixo ou travar. Não é erro de compilação, é erro de lógica.

Slide 8 · Desenvolver

Calcule a soma de duas matrizes M×N de números reais. As dimensões vêm do usuário e as matrizes são float ** com alocação dinâmica. Mostre a soma e libere a memória.

Ver solução
a8_ex_somamat.c
#include <stdio.h>
#include <stdlib.h>

float **alocar(int m, int n) {
    float **mat = malloc(m * sizeof(float *));
    int i;
    if (mat == NULL) return NULL;
    for (i = 0; i < m; i++) {
        mat[i] = malloc(n * sizeof(float));
        if (mat[i] == NULL) {                 // desfaz o que ja foi alocado
            while (i--) free(mat[i]);
            free(mat);
            return NULL;
        }
    }
    return mat;
}

void liberar(float **mat, int m) {
    int i;
    for (i = 0; i < m; i++) free(mat[i]);
    free(mat);
}

void ler(float **mat, int m, int n, char nome) {
    int i, j;
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++) {
            printf("%c[%d][%d]: ", nome, i, j);
            scanf("%f", &mat[i][j]);
        }
}

int main(void) {
    int m, n, i, j;
    float **A, **B, **C;

    printf("Linhas e colunas: ");
    scanf("%d %d", &m, &n);

    A = alocar(m, n);
    B = alocar(m, n);
    C = alocar(m, n);
    if (!A || !B || !C) {
        printf("Erro ao alocar memoria!\n");
        return 1;
    }

    ler(A, m, n, 'A');
    ler(B, m, n, 'B');

    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++)
            C[i][j] = A[i][j] + B[i][j];

    printf("\nA + B =\n");
    for (i = 0; i < m; i++) {
        for (j = 0; j < n; j++)
            printf("%6.2f ", C[i][j]);
        printf("\n");
    }

    liberar(A, m);
    liberar(B, m);
    liberar(C, m);
    return 0;
}

Separar alocar e liberar em funções evita repetir o laço três vezes (A, B e C). A função alocar também desfaz o que já reservou se algum malloc falhar no meio.

9.2O caractere '\0'

O %s e todas as funções de string.h andam pelo vetor até achar o '\0' (código ASCII 0). Por isso uma string com k letras precisa de k + 1 posições. Em char c[10] = "EE/CprE"; sobram 3 posições depois do texto.

Erros comuns (slide 5)

trecho
char c[10] = "EE/CprE";
printf("%s", c);          // EE/CprE
c[8] = 'a';
printf("\n%s", c);        // EE/CprE de novo: o '\0' da posição 7 ainda corta o texto

char c2[7] = "EE/CprE";   // compila, mas sem espaço para o '\0'
printf("%s", c2);         // errado: o printf continua lendo além do vetor

Mudar uma posição depois do '\0' não altera o que o %s mostra. Já o vetor c2 precisa de tamanho maior ou igual a 8.

O \n que o fgets guarda atrapalha comparações com strcmp. A solução dos slides remove ele com strcspn, que devolve a posição do primeiro caractere da string que está no conjunto dado:

#include <stdio.h>

#define N 50

int main(void) {

    printf("Nome completo: ");
    fgets(nome, sizeof(nome), stdin);        // le a linha inteira, com espacos
    nome[strcspn(nome, "\n")] = '\0';        // troca o '\n' por '\0'

    printf("Palavra: [%s]\nNome: [%s]\n", palavra, nome);
    return 0;
}

10.1Modelagem de registros

Um registro agrupa dados que descrevem a mesma entidade. Antes de escrever código, liste o que precisa representar:

  • Aluno: nome, matrícula, data de nascimento e média.
  • Produto: código, descrição, preço e quantidade.

O tipo de cada campo depende do significado do dado. CPF e telefone podem ser strings, porque ninguém faz conta com eles (e um CPF não cabe em int). Pergunta do slide: quais campos representariam um livro? Por exemplo título, autor, preço e quantidade.

10.2Struct

Um struct (registro) é uma estrutura heterogênea: reúne campos de tipos diferentes. Um vetor, ao contrário, reúne elementos do mesmo tipo.

sintaxe
struct nome_da_estrutura {
    tipo1 campo1;
    tipo2 campo2;
    /* ... */
};                         // o ponto e vírgula final é obrigatório
exemplo do slide
struct funcionario {
    int cod;
    char nome[30];
    float salario;
    int depto;
    char cargo;
};
// na main:
struct funcionario f1;     // sem typedef, a palavra "struct" é obrigatória

10.3typedef

typedef cria um apelido para um tipo que já existe. Não cria um tipo novo; só deixa a declaração mais curta e legível. Duas formas equivalentes:

typedef separado
struct funcionario { /* campos */ };
typedef struct funcionario func;
func f1;
typedef junto da struct
typedef struct funcionario {
    /* campos */
} func;
func f1;

A palavra depois da chave de fechamento (func) é o apelido. Os exemplos da Aula 10 usam nomes como AlunoRef, DataRef e ContaRef; na prova você escolhe o nome, mas o prototype do enunciado (por exemplo void exibirProduto(Produto p)) já diz qual apelido usar.

    d.y = p.y - q.y;
    return d;
}

int main(void) {
    ponto p1, p2, d;
    printf("Ponto 1 (x y): "); scanf("%f %f", &p1.x, &p1.y);
    printf("Ponto 2 (x y): "); scanf("%f %f", &p2.x, &p2.y);

    d = diferenca(p1, p2);
    printf("Diferenca: (%.2f, %.2f)\n", d.x, d.y);
    return 0;
}

A diferença de dois pontos também é um ponto, então a função devolve um ponto (retorno de struct por valor).

11.5Arquivos binários: fwrite e fread

Gravam blocos de bytes, o que permite salvar uma struct inteira de uma vez:

sintaxe
fwrite(buffer, tamanhoEmBytes, quantidade, ponteiroDeArquivo);
fread (buffer, tamanhoEmBytes, quantidade, ponteiroDeArquivo);
  • buffer: endereço de memória da estrutura (de onde ler no fwrite, onde guardar no fread). Para uma variável, &p; para um vetor, o próprio nome.
  • tamanhoEmBytes: tamanho de um elemento, quase sempre sizeof(Struct).
  • quantidade: quantos elementos transferir.
  • ponteiroDeArquivo: o FILE * aberto.

As duas devolvem a quantidade de elementos realmente transferidos. Compare com o que você pediu para detectar erro ou fim do arquivo (fread(...) == 1 em um laço lê registro por registro).

ModoSignificado

"wb"só escrita. Cria se não existir, apaga o conteúdo anterior se existir
"wb+"leitura e escrita. Cria ou apaga o conteúdo anterior

11.6Acesso direto: fseek, ftell, rewind

Normalmente o acesso é sequencial: cada leitura continua de onde a anterior parou. O fseek move a posição para qualquer lugar:

sintaxe
fseek(arquivo, deslocamento, origem);
OrigemConta o deslocamento a partir de
SEEK_SETinício do arquivo
SEEK_CURposição atual
SEEK_ENDfinal do arquivo

ftell(arq) devolve a posição atual em bytes e rewind(arq) volta ao início. A fórmula mais cobrada: o registro de índice i (começando em 0) começa no byte i * sizeof(Struct). O quarto registro é o índice 3.

a11_binario.c (exemplo do slide 13)
#include <stdio.h>

typedef struct alunos {
    int matricula;
    char nome[10];
    int idade;
} alunos;

int main(void) {
    FILE *farq;
    alunos al, alun[4] = {
        {1, "Maria", 20}, {2, "Ana", 19}, {3, "Carlos", 16}, {4, "Celso", 19}
    };

    farq = fopen("alunos.bin", "wb");              // wb: escrita binaria
    if (farq == NULL) return 1;
    fwrite(alun, sizeof(alunos), 4, farq);         // grava 4 registros de uma vez
    fclose(farq);

    farq = fopen("alunos.bin", "rb");              // rb: leitura binaria
    if (farq == NULL) return 1;
    fseek(farq, 3 * sizeof(alunos), SEEK_SET);     // pula 3 registros a partir do inicio
    fread(&al, sizeof(alunos), 1, farq);           // le o quarto registro
    printf("%d\n%s\n%d\n", al.matricula, al.nome, al.idade);
    printf("posicao atual: %ld bytes\n", ftell(farq));
    fclose(farq);
    return 0;
}

Abra com "rb+", encontre o registro, volte com fseek ao início dele (a leitura avançou a posição) e dê fwrite. Entre uma leitura e uma escrita no mesmo arquivo o padrão exige um fseek (ou rewind). Veja a solução da Lista D19.

Exercício 4 · struct dinâmica

Crie uma struct Aluno (nome, nota). Leia a quantidade de alunos e aloque dinamicamente um vetor de Aluno. Crie float calcularMedia(const Aluno alunos[], int n);. Exiba a média da turma e quantos alunos tiveram nota maior ou igual a 6,0. Libere a memória.

Ver solução
a12_ex4_alunos.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char nome[50];
    float nota;
} Aluno;

float calcularMedia(const Aluno alunos[], int n) {
    float soma = 0;
    int i;
    for (i = 0; i < n; i++)
        soma += alunos[i].nota;
    return soma / n;
}

int main(void) {
    int n, i, aprovados = 0;
    Aluno *alunos;

    printf("Quantidade de alunos: ");
    scanf("%d", &n);
    getchar();
    alunos = malloc(n * sizeof(Aluno));            // n structs, nao n bytes
    if (alunos == NULL) { printf("Erro na alocacao\n"); return 1; }

    for (i = 0; i < n; i++) {
        printf("Nome do aluno %d: ", i + 1);
        fgets(alunos[i].nome, sizeof(alunos[i].nome), stdin);
        alunos[i].nome[strcspn(alunos[i].nome, "\n")] = '\0';
        printf("Nota: ");
        scanf("%f", &alunos[i].nota);
        getchar();
        if (alunos[i].nota >= 6.0f) aprovados++;
    }
    printf("Media da turma: %.2f\n", calcularMedia(alunos, n));
    printf("Alunos com nota >= 6.0: %d\n", aprovados);
    free(alunos);
    return 0;
}

Note malloc(n * sizeof(Aluno)): o sizeof é do tipo struct. Um vetor Aluno * se passa para um parâmetro const Aluno alunos[] sem conversão nenhuma.

Leia 5 inteiros em um vetor. Crie void salvarNumeros(const int vet[], int tamanho);, que grava os números em "numeros.txt", um por linha, com fprintf(). No main, reabra o arquivo para leitura e exiba os valores com fscanf(). Use os modos "w" e "r", verifique a abertura e feche os arquivos.

#include <stdio.h>

void salvarNumeros(const int vet[], int tamanho) {
    int i;
    FILE *fp = fopen("numeros.txt", "w");
    if (fp == NULL) {
        printf("Erro ao abrir numeros.txt para escrita.\n");
        return;
    }
    for (i = 0; i < tamanho; i++)
        fprintf(fp, "%d\n", vet[i]);
    fclose(fp);

    int v[5], i, x;
    FILE *fp;

        return 1;

Exercício 6 · arquivo binário

Crie uma struct Produto (código, nome, preço). Leia 3 produtos em um vetor e crie void salvarProdutos(const Produto vet[], int n);, que grava os registros em "produtos.bin" com fwrite() e modo "wb". No main, reabra com "rb", use fread() e exiba os produtos. Feche o arquivo após cada operação.

Ver solução
a12_ex6_produtos.c
#include <stdio.h>
#include <string.h>

typedef struct {
    int codigo;
    char nome[30];
    float preco;
} Produto;

void salvarProdutos(const Produto vet[], int n) {
    FILE *fp = fopen("produtos.bin", "wb");
    if (fp == NULL) { printf("Erro ao criar produtos.bin\n"); return; }
    if (fwrite(vet, sizeof(Produto), n, fp) != (size_t)n)
        printf("Erro ao gravar.\n");
    fclose(fp);                                   // fecha apos a operacao
}

int main(void) {
    Produto v[3], lido[3];
    int i, n;
    FILE *fp;

    for (i = 0; i < 3; i++) {
        printf("Codigo, nome (sem espaco) e preco: ");
        scanf("%d %29s %f", &v[i].codigo, v[i].nome, &v[i].preco);
    }
    salvarProdutos(v, 3);

    fp = fopen("produtos.bin", "rb");
    if (fp == NULL) { printf("Erro ao abrir produtos.bin\n"); return 1; }
    n = (int)fread(lido, sizeof(Produto), 3, fp);   // devolve quantos registros leu
    fclose(fp);

    for (i = 0; i < n; i++)
        printf("%d | %-10s | R$ %.2f\n", lido[i].codigo, lido[i].nome, lido[i].preco);
    return 0;
}

O vetor vai direto no fwrite (já é um endereço) e fread devolve quantos registros leu, que é o que o laço de exibição usa.

  6. A6
    Leia N inteiros (N definido pelo usuário) em um vetor e, por uma função, ordene em ordem crescente e exiba.
    Dica

    O vetor chega à função como ponteiro, então a função altera o original. Selection ou bubble sort.

    Solução em C
    l_a6_ordenar.c
    #include <stdio.h>
#include <stdlib.h>

void ordenar(int *v, int n) {                 // selection sort
    int i, j, menor, aux;
    for (i = 0; i < n - 1; i++) {
        menor = i;
        for (j = i + 1; j < n; j++)
            if (v[j] < v[menor]) menor = j;
        aux = v[i]; v[i] = v[menor]; v[menor] = aux;
    }
}

int main(void) {
    int n, i, *v;
    printf("N: ");
    scanf("%d", &n);
    v = malloc(n * sizeof(int));
    if (v == NULL) return 1;
    for (i = 0; i < n; i++) scanf("%d", &v[i]);

    ordenar(v, n);                             // v ja e ponteiro: a funcao altera o original
    for (i = 0; i < n; i++) printf("%d ", v[i]);
    printf("\n");
    free(v);
    return 0;
}

    Cálculo de média de alunos: duas avaliações com pesos 4 e 6, aprovação com média 6. Aloque dinamicamente vetores de RA (7 dígitos), nota1, nota2 e média. Entrada: RA, nota1, nota2 (RAs fora de ordem). Saída em ordem crescente de RA: RA, nota1, nota2, média e situação.
    Dica

    Média = (4·n1 + 6·n2) / 10. Ordene pelo RA e troque as posições nos quatro vetores ao mesmo tempo, senão os dados se separam.

    Solução em C
    l_a7_professor.c
    #include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n, i, j, k, ra_aux;
    int *ra;
    float *n1, *n2, *media, f;

    printf("Numero de alunos: ");
    scanf("%d", &n);
    ra    = malloc(n * sizeof(int));
    n1    = malloc(n * sizeof(float));
    n2    = malloc(n * sizeof(float));
    media = malloc(n * sizeof(float));
    if (!ra || !n1 || !n2 || !media) { printf("Sem memoria.\n"); return 1; }

    for (i = 0; i < n; i++) {
        printf("RA nota1 nota2: ");
        scanf("%d %f %f", &ra[i], &n1[i], &n2[i]);
        media[i] = (4 * n1[i] + 6 * n2[i]) / 10;        // pesos 4 e 6
    }

    // ordena por RA; os 4 vetores "andam juntos" (selection sort)
    for (i = 0; i < n - 1; i++) {
        k = i;
        for (j = i + 1; j < n; j++)
            if (ra[j] < ra[k]) k = j;
        ra_aux = ra[i]; ra[i] = ra[k]; ra[k] = ra_aux;
        f = n1[i];    n1[i] = n1[k];       n1[k] = f;
        f = n2[i];    n2[i] = n2[k];       n2[k] = f;
        f = media[i]; media[i] = media[k]; media[k] = f;
    }

    printf("\n%-8s %6s %6s %6s  %s\n", "RA", "N1", "N2", "Media", "Situacao");
    for (i = 0; i < n; i++)
        printf("%07d %6.1f %6.1f %6.2f  %s\n", ra[i], n1[i], n2[i], media[i],
               media[i] >= 6 ? "aprovado" : "reprovado");

    free(ra); free(n1); free(n2); free(media);
    return 0;
}

    #include <stdio.h>

int main(void) {
    int m[3][3], i, j, det;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++) {
            printf("m[%d][%d]: ", i, j);
            scanf("%d", &m[i][j]);
        }

void verificarTamanho(char *texto, int tamanhoEsperado) {

    char s[] = "Ola mundo";       // vetor (modificavel); com char *s = "..." daria erro
    inverteString(s);
    printf("%s\n", s);            // odnum alO
    return 0;
}
odnum alO

Na prática o argumento precisa ser um vetor (char s[] = "Ola mundo";). Se for passado um literal (char *s = "Ola mundo";), a troca tenta escrever em memória somente leitura e o programa falha.

Questão 6 · arquivos

Analise as afirmações sobre fopen, fseek, fwrite e fread:

I. fopen com o modo "rb" abre um arquivo para leitura em modo binário; se o arquivo não existir, a abertura falha.
II. fseek reposiciona o ponteiro do arquivo para uma posição específica, usando um deslocamento e uma referência (início, atual ou fim).
III. fwrite grava dados em um arquivo aberto.
IV. fread pode ser usada para ler estruturas inteiras de um arquivo binário, desde que o ponteiro e o tamanho estejam corretamente especificados.

Quais são verdadeiras?

I: modos r exigem que o arquivo exista (Aula 11, tabela de modos binários). II: origens SEEK_SET, SEEK_CUR e SEEK_END. III: é a escrita de blocos (o arquivo precisa estar aberto em modo de escrita). IV: é exatamente o uso de fread(&registro, sizeof(Registro), 1, fp). Todas corretas.

O malloc recebe bytes: 20 elementos × sizeof(int).

2. Uma matriz int **m tem 3 linhas. Qual a ordem correta para liberar?

Se você liberar m primeiro, perde o acesso às linhas (e usar m[i] depois é uso de memória liberada).

3. Com char s[5] = "Ola";, quanto valem strlen(s) e sizeof(s)?

strlen conta as letras até o '\0' (3). sizeof é o tamanho declarado do vetor (5).

4. Para verificar se o texto lido em nome é igual a "USF", o correto é:

strcmp devolve 0 para strings iguais. == compara endereços.

5. Qual é a saída?

trecho
typedef struct { int x; } P;
void inc(P p)   { p.x++; }
void inc2(P *p) { p->x++; }
/* main */
P a = {1};
inc(a);
inc2(&a);
inc(a);
printf("%d", a.x);

Só inc2 altera o original (recebe o endereço): 1 → 2. As duas chamadas a inc mexem em cópias.

6. Qual afirmação sobre b = a; (duas structs do mesmo tipo) é verdadeira?

A atribuição de struct copia byte a byte todos os campos. O que não pode é atribuir um vetor solto (b.nome = a.nome).

7. Qual modo de fopen acrescenta dados no final de um arquivo de texto, preservando o conteúdo?

"w" e "w+" apagam o conteúdo anterior; "r" não escreve.

8. Cada Reg ocupa 32 bytes. fseek(fp, 2 * sizeof(Reg), SEEK_SET); fread(&r, sizeof(Reg), 1, fp); lê qual registro?

Pular 2 registros deixa a posição no início do terceiro (índice 2).

9. O que há de errado?

trecho
int *p = malloc(5);

Seriam necessários 5 * sizeof(int) bytes (20 em geral). p[4] ocupa os bytes 16 a 19.

10. Depois de fgets(s, sizeof(s), stdin); com a entrada abc + Enter, o que contém s?

O fgets guarda o \n digitado. Por isso se usa s[strcspn(s, "\n")] = '\0'; antes de comparar ou medir.
